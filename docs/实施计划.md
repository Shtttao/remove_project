# 机器人 IMU 模块移植实施计划

目标为 X Pulse STM32H563VIT6（LQFP100，2 MB Flash）配合 ICM-42688-P，先交付能在 VS Code 编译、在主机测试、能进入台架联调的固件。替换验收还需旧模块、接收端和新板实测。

## 实施顺序与验收

1. **目标板工程与工具链**。以 ST 的 STM32H563 设备定义和启动文件、Arm GNU Toolchain、Make 和 VS Code 工作区任务构建。使用 Cortex-M33 单精度浮点，先以片内时钟工作。产出 ELF、BIN、MAP，检查架构、复位向量、Flash 与 RAM 范围。
2. **ICM-42688-P 驱动**。台架使用四线 SPI，抽离寄存器传输与延时，核对身份、软复位、设置并读回量程和 ODR。初版 200 Hz、±2 g、±2000 °/s，从寄存器突发读取六轴与温度。用模拟寄存器测试正常、无新数据、错误 ID、传输失败、有符号字节和单位。
3. **校准与姿态**。先连续收集静止样本计算陀螺零偏。使用实际时间戳，融合加速度重力方向与角速度，输出单位四元数；确认安装方向后再对准机器人轴。主机验证静止、已知转角、倾斜和异常间隔。六轴模块的航向是相对角，静态重力无法校正航向漂移。
4. **旧 UART2 遥测**。对照旧源码打包 A1/A2/A3，轮流输出，暂用独立台架版本标识。模拟样本通过完整采样、解算和编码链。接收端命令、双串口差异、Flash 配置、旧引导/升级、里程计辅助在对照实物和上位机后分项迁移。
5. **VS Code 和复验**。工作区提供主机测试、目标构建与二进制检查入口。先验证失败场景，再正常构建、运行测试、检查固件布局，记录工具版本、操作入口与结果。
6. **实板联调**。确认小板电压、总线引脚、共地、CS 和 SWD、现有引导及镜像备份；核对 WHO_AM_I 为 0x47、逻辑分析仪上的时序、真实数据率和六面重力，随后做已知角度旋转、静止漂移及新旧串口抓包回放。最后在机器人上检查启动、掉线恢复和长时间运行。数据率、噪声、漂移、兼容性只有测量后才登记为通过。

X Pulse 台架接线见 [README](../README.md#首次台架接线)。MCU 按独立启动、TrustZone 关闭构建，使用片内 HSI。旧 F103 主循环用 LED 指示运行，新板使用低有效的 PC0 灯显示 IMU 搜索、校准和已校准状态。

器件、电气与复用功能以原厂资料为准。[ST 数据手册 DS14258](https://www.st.com/resource/en/datasheet/stm32h563vi.pdf) · [ST 设备支持包](https://github.com/STMicroelectronics/cmsis-device-h5) · [TDK ICM-42688-P 产品与数据手册](https://www.invensense.tdk.com/en-us/products/6-axis/icm-42688-p)
